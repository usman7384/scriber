# M1 vertical slice (integrator)

Built in this session, sequentially, because every later service depends on the IR and the build loop.

## What exists

- `services/ir`: `Design` (params with unit/bounds/provenance, sketches on XY/XZ/YZ, extrude, revolve, hole with grid/polar/point placement, fillet, chamfer, shell), safe expressions, validation (references, positive dimensions, unused parameters), deterministic compiler to a parametric build123d script, `apply_params`, `diff`.
- `services/geometry`: warm worker subprocess, import allow-list and blocked builtins, timeout and crash recovery, STEP/STL/GLB export, per-part metrics, holes recognised from the B-rep, validity findings, kernel errors mapped to the failing feature.
- `services/agent`: `LLM` protocol with Ollama and fake adapters; requirement extraction grounded in the request text; schema-constrained IR emission with four worked examples; build → checks → repair loop; refinement as parameter updates or a new design.
- `apps/cli`: `scriber generate | refine | params`, versioned output folders; failed versions are never used as a base.
- `evals`: 10 M1 cases with hand-written checks, harness and scorecard.

## Eval, 2026-10-25 (`evals/results/m1-20261025-210241`)

| model | built | valid | checks | all checks pass | repairs | median s |
|---|---|---|---|---|---|---|
| qwen3.5:4b | 7/10 | 7/10 | 22/35 | 4/10 | 21 | 145 |
| qwen2.5-coder:7b q4_K_M | 9/10 | 8/10 | 22/35 | 3/10 | 27 | 172 |

The 4B stays the default (D-002): more cases fully correct, fewer repairs, faster, and it is multimodal.

Failure classes: holes not cut on non-trivial parts (flange adapter, L-bracket upright, T-plate), standards knowledge (DN50 flange), pattern geometry (NEMA 31 mm square came out 29.5), and dropped dimensions (box height 24 instead of 40).
