## What is there

- **Layout** (`src/workspace/Workspace.tsx`, `workspace.css`): the workspace is fixed over the page; the viewport fills it and the top bar, structure rail, inspector, agent stream, command bar and versions float over it. The rail (224 px) and inspector (324 px) collapse; below 1100 px the rail is a 44 px icon strip; below 768 px the inspector, Activity and Versions share a bottom sheet with peek / half / full snap points (tap or drag the handle) and the command bar sits on the sheet's bottom edge.
- **Viewport** (`src/viewer`): the free area is a CSS box inset by `--frame-t/r/b/l`; its measured rect drives `setViewOffset` and the fit distance or zoom, so the part is framed between the panels. Top / Front / Right are orthographic, Iso is perspective. Ground grid on z = 0 (1 / 10 / 100 mm, major every 10, fading radially), short X / Y origin lines, a DOM axis triad turned every frame. Colours come from tokens via `usePalette`, re-read when `data-theme` changes.
- **Dimensions**: the bounding box drawn as L / W / H drafting dimensions with extension lines and slash ticks; chips are reference values, parenthesised by CSS (text stays `L 120.0 mm`). A picked face shows its parameter as a driving chip on a leader along the face normal: type, arrows step (Shift x10, Alt x0.1), Enter sends one PATCH, Esc cancels.
- **Finding pins**: severity glyph at `location.point`, dashed ring, leader to a callout (message, measured · required, suggestion, rule) on hover, focus or selection, with Ask agent to fix (a refine request built from the finding, targeting its part) and Show rule (opens the project's Sources route). Pins are tab stops after the HUD.
- **Inspector** (`src/workspace/inspector`): overview (facts, checks, parameters), part (material, parent, joint), face (the face edit form and the driving parameter pinned on top), finding (measured, required, rule, suggestion, Ask agent to fix), version preview (read-only values with what they were). Esc clears the selection once popovers and menus are closed.
- **Parameters** (`src/workspace/params`): label, provenance monogram (a button opening the source, quote and ref, with Open in Sources for documents and rules), mono value field with the unit inside, hairline slider with its bounds, edited dot and "was", out-of-bounds message naming the bound (blocks Apply), Live switch (accessible name `Apply instantly`, same 400 ms debounce), "Apply n changes" and Reset.
- **Top bar**: mark, breadcrumb to the project, title `h1`, version, the checks pill (pass / warn / fail glyphs and assumed count) opening one popover with requirements, manufacturability, assumptions and printability, Report a bug, Share (popover with link, Copy, Revoke), and Deliver (STEP, STL, GLB, script, IR, FreeCAD disabled with its reason when the server has no FreeCAD, Publish to Explore, Check printability).
- **Structure rail**: component tree nested by parent with ids, a visibility toggle per part, Alt-click to isolate, the picked face as a child row; counted links to Sources, Checks, Assumptions (focuses the first assumed value) and Proposals.
- **Shared page**: the same workspace read-only: no rail or command bar, values as a table, Deliver lists only the shared files. It still requests only `GET /s/{id}` and its GLB.
- **Specs**: `e2e/workspace.spec.ts` covers the package's acceptance list; `SHOTS=<dir> npx playwright test workspace -g screenshots` writes the screenshots.
