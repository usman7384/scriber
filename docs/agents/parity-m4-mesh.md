# M4 mesh rows: mesh → parametric IR

Branch `feat/m4-mesh`. Changes `services/geometry` (reconstruction, Hausdorff) and `evals` (demos, fixtures).

## What exists

- `partwright_geometry.reconstruct_mesh(path) -> Design`: deterministic, no model. It loads a watertight STL/OBJ (merging vertices to 1e-4 mm and dropping degenerate faces), finds planar levels normal to Z from an area histogram of flat faces, cuts one section per slab between levels, and emits typed IR:
  - each run of slabs with the same outline is an `extrude` (`body`, `boss_1`, …) on a plane whose offset is the sum of the height parameters below it, so editing `thickness` moves everything above;
  - circles are fitted by least squares on the tessellation vertices of near-vertical faces (they lie on the true surface, unlike section points on chords), with MAD trimming; other outlines become counter-clockwise polygons simplified to `0.02 mm + 3σ`;
  - two or more equal circular openings with the same depth become one `hole` feature with a polar or grid placement when the centres fit it within 0.05 mm; a single circle is a `bore` cut, any other opening a `window` cut;
  - every parameter (`outer_diameter`, `thickness`, `boss_1_height`, `hole_diameter`, `hole_pcd`, …) has unit mm, bounds [v/2, 2v] and `mesh_fit` provenance with the fit residual.
  - The scan noise σ is estimated from the spread of the planar faces and scales the tolerances; section loops smaller than (10σ)² mm² are dropped as noise folds.
- `partwright_geometry.hausdorff(a, b)`: symmetric, over all vertices plus 20 000 seeded surface samples per side. A KD-tree over triangle centroids gives an upper bound per point; the points that could set the maximum are then measured exactly against every triangle, so the result is exact for that point set.
- `partwright_ir.replace(design, new, part_id)`: swaps one part of an assembly; the new part must carry connectors with the ids the old part had, so every joint keeps resolving. The old part's unused params are dropped and the new params merge strictly (a clash with another value is an error).
- Fixtures in `evals/parity/m4/mesh/`: `to_assembly.json` (CD-4 assembly), `flange.json` (IR, built and exported at run time), `mount.json` (IR; the demo subdivides its STL to 2 mm edges and adds seeded σ = 0.1 mm Gaussian noise per vertex), `to_bracket.stl` + `to_bracket.json` (ground-truth holes), regenerated byte-identically by `uv run python evals/parity/m4/mesh/make_fixtures.py`. The bracket is a planar topology-optimisation-style truss: bars and bosses blended by a 4 mm morphological closing, all edges filleted R1.2, 8 mm thick. The script imports build123d directly; it is a fixture tool, not a package module.

## Gaps

- Only Z-stacked prismatic shapes: the dominant planar direction must be world Z. No axis detection or re-orientation, no revolve, taper, draft, fillet or chamfer recovery (blends are rebuilt sharp), no varying-thickness organic shapes. A 3D topology-optimisation result would not reach 1 %; this fixture is the planar (extrusion-constrained) kind.
- Holes are fitted with their axis fixed to Z; tilted holes are not detected. Openings smaller than (10σ)² mm² (1 mm² at σ = 0.1) are dropped.
- Free-form outlines are polygons, not line/arc paths, so they carry no named parameters.
- Not wired into the agent, API upload or CLI yet; `IN-7` names `services/agent`, which can call `reconstruct_mesh` as a tool.
- CD-4: the original bracket in the assembly is its design-space plate (same mount pattern and thickness); the organic TO shape exists only as the STL. Placement error is 0 because the hole grid is recovered exactly; a noisy-scan replacement is not part of the row.
