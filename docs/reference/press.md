## S14 DEVELOP3D, "Kyrall launches its AI automated CAD modeller" (2026-07-06)
URL: https://develop3d.com/cad/kyrall-launches-its-ai-automated-cad-modeller/ (byline: DEVELOP3D)

- Largely restates the launch post (S13): engineering data (specs, requirements, sizing results) → parametric, manufacturable models in minutes; functional assemblies from in-house knowledge; design intent and best practices captured.
- User describes the need; more context → output closer to the team's way of working; real-time dimension adjustment and refinement before export; export GLB, STL, STEP for CAD or direct manufacture.
- Context Manager as headline feature; checks output against input; consistent with team practice.
- Quote attributed to co-founder Osama Atwi: specs, past parts and design processes are turned into a knowledge graph used to design parts, with design intent embedded in assemblies. Short quote: "Until now, mechanical design has been purely a manual process."
- Release extras: updated UI, API, faster generation.
- Not stated: pricing, funding, model details, benchmarks.
